# KinéAnat — prototype partageable

Cette version reprend le prototype KinéAnat V37 avec la carte anatomique, le parcours, les questions et les annotations 3D de la cheville.

## Identifiants de démonstration

- Identifiant : `kineanat`
- Mot de passe : `berliners`

## Mise en ligne sur GitHub Pages

1. Crée un dépôt GitHub.
2. Place `index.html` à la racine du dépôt.
3. Va dans **Settings → Pages**.
4. Choisis **Deploy from a branch**, puis la branche principale et le dossier `/ (root)`.
5. Ouvre l'adresse GitHub Pages fournie par GitHub.

## Important concernant le mot de passe

La protection incluse ici est une **barrière côté navigateur**, pratique pour une démo entre amis, mais ce n'est **pas une authentification serveur**. Le code HTML/JavaScript est téléchargé par le navigateur et un utilisateur technique peut retrouver ou contourner cette protection.

Pour protéger réellement l'accès à une version hébergée publiquement, il faut placer une authentification en amont (par exemple Cloudflare Access, un reverse proxy avec authentification, ou un hébergement disposant d'une authentification serveur).
